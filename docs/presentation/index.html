DIRECTION A · RECOMMANDÉELe compte rendu

Le deck est traité comme un compte rendu imprimé. Une marge de cote porte le numéro de scrutin, la date et la source ; deux colonnes portent le texte. La neutralité se voit dans la forme du document, pas dans un slogan.

« Deux décomptes, le même jour, sur le même article. »La phrase qui porte

DIRECTION BLa chambre

DIRECTION CLe dossier

Le deck est la chemise de l'affaire : pièces numérotées, bordereau, tampon de contrôle. Le passage gate 5 est un tampon sur le fichier, jamais sur la loi. Thème clair de lecture, tableaux plutôt que cartes.
