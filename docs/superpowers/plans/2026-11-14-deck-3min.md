# Deck 3 minutes + Recommencer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un oral de 3:00 en 5 diapos calé sur la grille du jury, et un bouton qui remet un devoir à zéro pour enchaîner les démos locales.

**Architecture:** HTML/CSS/JS natifs, aucune dépendance. Le deck réutilise le CSS et le script de navigation de `docs/presentation/deck-a.html`. Le bouton s'ajoute au déléguateur `data-action` existant dans `js/app.js`.

**Tech Stack:** HTML, CSS, JavaScript natif ; vérification `node --check` + parcours navigateur.

**Spec:** `docs/superpowers/specs/2026-11-14-deck-3min-design.md`

## Global Constraints

- Aucune dépendance, aucun framework, aucun appel réseau ajouté dans l'app.
- Le vote reste dans `localStorage` sous la clé `quorum.v1` ; rien n'est envoyé.
- Neutralité : aucun avis sur les lois ; « non documenté » quand il n'y a pas de source.
- Chiffres de coût : 0,08 à 0,15 € par loi (mesuré) ; prix d'abonnement marqué « hypothèse ».
- UTF-8 sans BOM ; ne rien publier vers un service externe.
- Exécution : native, dans cette session (choix de l'utilisateur, qui a validé le périmètre).

## Review Focus

- Le bouton efface une autre loi ou l'intro : test à l'étape 3 de la tâche 1, on vérifie que seule la loi courante est effacée.
- Clic accidentel pendant la démo : `window.confirm` exigé à l'étape 2 de la tâche 1.
- Cache navigateur/service worker servant l'ancien `app.js` : versions `v30` à l'étape 4 de la tâche 1.
- Diapo 4 lue comme un prix validé : le mot « hypothèse » doit figurer sur la diapo, vérifié à l'étape 2 de la tâche 2.
- Texte qui déborde à 1920 × 1080 : contrôle visuel à l'étape 3 de la tâche 2.
